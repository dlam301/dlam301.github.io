F1 Learning App - Documentation

What is this app?

The F1 Learning App is an educational Progressive Web App that teaches users basic Formula 1 terminology. Users can select a topic from the dropdown menu to read a description, view an image when available, and hear the description through either an audio file or text-to-speech.

Features

  • Dropdown menu populated from a JSON file
  • Eight Formula 1 learning topics
  • Written explanation for each topic
  • Images for selected topics when available
  • Audio playback or text-to-speech support
  • Installable as a Progressive Web App
  • Offline support through a service worker

How to Use the App

  1. Open the F1 Learning App page.
  2. Use the dropdown menu to select a Formula 1 topic.
  3. Read the description shown on the page.
  4. If an image is available, it will appear below the description.
  5. Click the audio button to hear an audio file or text-to-speech reading.

How to Install

  1. Open the app in a modern browser such as Google Chrome or Microsoft Edge.
  2. Look for the install icon in the browser address bar.
  3. Click install to add the app to your device.
  4. On mobile, open the browser menu and choose "Add to Home Screen."
  5. After installation, the app can be launched like a regular app.

Offline Use

After the app has been opened once, the service worker stores important app files in the browser cache. This allows the app to continue working even when the user is offline.
