How the App Works

The app uses app.html for the page structure, style.css for visual styling, app.js for interactivity, data.json for topic content, manifest.json for PWA installation settings, and sw.js for offline caching.

Main Files

  • app.html: creates the main structure of the app page
  • style.css: controls colors, spacing, fonts, and layout
  • app.js: loads the JSON file and updates the page when a topic is selected
  • data.json: stores all Formula 1 topic information
  • manifest.json: provides install settings for the PWA
  • sw.js: caches app files so the app can work offline

How to Add a New Topic

All learning content is stored in data.json. To add a new topic, open data.json and add a new object inside the f1 array. 

{
    "title": "Your Topic Title",
    "description": "Your description here.",
    "image": "your_image_filename.jpg",
    "audio": "your_audio_filename.mp3"
}

JSON Field Explanations

  • The title field controls the name shown in the dropdown menu.
  • The description field controls the text displayed on the page.
  • The image field controls which image appears for that topic.
  • The audio field controls which audio file plays for that topic.

Notes for Editing

  • The image field can be left as empty quotes "" if no image is available.
  • The audio field can be left as empty quotes "" if no audio file is available.
  • If the audio field is empty, the app uses text-to-speech instead.
  • Image and audio files should be placed in the same folder as app.html unless the file path is changed.
  • Any new files that should work offline should also be added to the staticAssets list in sw.js.
  • If major changes are made, the cache name in sw.js can be updated to force the browser to refresh cached files.
