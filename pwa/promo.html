F1 Learning App

The F1 Learning App is an educational Progressive Web App that helps users learn basic Formula 1 terminology. It includes a JSON-powered topic menu, written explanations, selected images, audio or text-to-speech, and offline support.

App Purpose

  • Learn common Formula 1 terms in a simple format
  • Select topics from a dropdown menu
  • View supporting images when available
  • Use audio or text-to-speech to hear explanations
  • Install the app and use it offline

App Screenshot

How to Download or Install

  1. Open the app link in Google Chrome or Microsoft Edge.
  2. Click the install icon in the browser address bar, if it appears.
  3. On mobile, open the browser menu and choose "Add to Home Screen."
  4. After installation, open the app from your device like a regular application.
